BARANUS LAUNCHER — ПЛАН ПРОЕКТА

1. ЛАУНЧЕР
- Продолжать улучшать интерфейс, страницы сборок и их стили.
- Сохранить отдельные темы, музыку и навигацию для: главного меню, космической сборки, SCP и Vanilla.
- Закончить и проверить настройки окна: разрешение, полноэкранный режим, сворачивание или закрытие после запуска Minecraft.
- Перед каждым новым релизом собирать EXE, Setup, latest.yml и blockmap.
- Проверять автообновление на установленной Setup-версии, а не только на портативном EXE.

2. САЙТ BARANUS
- Сделать главную страницу с новостями, описанием сборок и ссылкой на загрузку лаунчера.
- Добавить страницу правил, поддержки и статуса сервера.
- Сначала публиковать тестовую версию сайта по временной ссылке.
- Когда сайт будет готов, подключить собственный домен и включить индексацию Google.

3. ЛИЧНЫЙ КАБИНЕТ И АККАУНТЫ
- Определить модель входа: собственный аккаунт Baranus.
- Если нужны собственные аккаунты: создать API, базу PostgreSQL, регистрацию, вход, восстановление доступа и профиль пользователя.
- В кабинете показать ник, статус, новости, правила, историю наказаний или игровую статистику — только после появления серверной части.

4. БЕЗОПАСНОСТЬ
- Сайт и API работают только по HTTPS.
- Пароли хранятся только в виде безопасного хеша Argon2id, без открытого текста.
- Ключи, токены и пароли базы данных не попадают в EXE, репозиторий и клиентский код сайта.
- API защищается ограничением попыток входа, проверкой данных и короткоживущими токенами.
- База данных закрыта от прямого доступа из интернета; доступ к ней есть только у серверной части.
- Регулярно делать резервные копии базы данных.

5. СВЯЗКА ЛАУНЧЕРА И MINECRAFT-СЕРВЕРА
- Лаунчер показывает окно входа и получает токен от API.
- Лаунчер передаёт краткоживущий токен в запуск игры.
- Серверный Forge-мод или прокси проверяет токен и разрешает вход.
- Проверка должна быть на сервере: нельзя доверять только тому, что сообщает лаунчер.

6. ПОРЯДОК РАБОТЫ
1) Завершить интерфейс и релиз лаунчера.
2) Собрать тестовый сайт и показать его по временной ссылке.
3) Подключить домен и Google Search Console.
4) Создать API и базу данных.
5) Добавить безопасный вход в личный кабинет.
6) Связать авторизацию с лаунчером и сервером.
