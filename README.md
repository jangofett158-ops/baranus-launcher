# Forge 1.12.2 Launcher

Минимальный Windows-лаунчер для **Minecraft Forge 1.12.2 (14.23.5.2859)**. При первом запуске скачивает официальные игровые файлы, Forge и набор модов в `Документы/Forge-1.12.2`.

В сборку автоматически входят Galacticraft Legacy 4.0.7, Iron Chests 7.0.72.847 и JEI 4.16.1.302. В окне отображается шкала загрузки: точный процент для Java и модов, анимация во время загрузки Minecraft/Forge.

## Запуск

1. Установите [Node.js LTS](https://nodejs.org/). Java отдельно не нужна: лаунчер сам скачает официальную Temurin Java 8 в папку игры при первом запуске.
2. В папке проекта выполните `npm install`.
3. Выполните `npm start`.
4. В лаунчере укажите ник и нажмите «Установить и играть».

Для создания одного `.exe` выполните `npm run pack`. Он появится в папке `dist`.

## Важно

Текущая версия запускает игру в офлайн-режиме — для одиночной игры и серверов с отключённой онлайн-проверкой. Для официальных серверов потребуется добавить вход Microsoft/Xbox.

Forge 1.12.2 требует Java 8. Лаунчер сам использует изолированную Java 8, поэтому системные Java 17/21 не повлияют на игру.

## Как добавить мод в автозагрузку

1. Найдите `.jar` мода именно для **Forge 1.12.2** и получите прямую ссылку на файл.
2. Откройте `src/main.js` и найдите массив `const MODS = [`.
3. Добавьте строку перед закрывающим `];`, например:

   ```js
   { name: 'Название мода 1.0', file: 'mod-1.0-1.12.2.jar', url: 'https://example.com/mod-1.0-1.12.2.jar' },
   ```

4. `file` должен точно совпадать с именем скачиваемого `.jar`, а `url` обязан вести на сам `.jar`, не на страницу сайта.
5. Пересоберите лаунчер: `npm run pack`. Новый файл появится в папке, указанной в `package.json` → `build.directories.output`.

Локально, без пересборки, можно просто скопировать `.jar` в `Документы/Forge-1.12.2/mods`.

## Автообновления через GitHub Releases

Лаунчер проверяет новые версии в репозитории `jangofett158-ops/baranus-launcher`. Чтобы выпустить обновление:

1. В `package.json` увеличьте поле `version`: например, `0.1.1` → `0.1.2`.
2. Соберите новый файл командой `npm run pack`.
3. На GitHub откройте **Releases** → **Draft a new release**.
4. В поле тега укажите версию с `v`: `v0.1.2`.
5. Прикрепите именно файл с именем `Baranus-Launcher.exe` и опубликуйте релиз.

При следующем запуске старого лаунчера пользователю появится кнопка «Обновить до 0.1.2». После нажатия новая версия скачивается, заменяет старый `.exe` и запускается.
