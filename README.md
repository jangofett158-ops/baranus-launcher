# Forge 1.12.2 Launcher

Минимальный Windows-лаунчер для **Minecraft Forge 1.12.2 (14.23.5.2859)**. При первом запуске скачивает официальные игровые файлы, Forge и набор модов в `Документы/Forge-1.12.2`.

В сборку автоматически входят Galacticraft Legacy 4.0.7, Iron Chests 7.0.72.847 и JEI 4.16.1.302. В окне отображается шкала загрузки: точный процент для Java и модов, анимация во время загрузки Minecraft/Forge.
