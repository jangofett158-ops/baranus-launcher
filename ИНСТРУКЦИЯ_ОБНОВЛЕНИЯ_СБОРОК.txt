BARANUS LAUNCHER — РУЧНОЕ ОБНОВЛЕНИЕ СБОРОК

ЭТА ИНСТРУКЦИЯ УПРАВЛЯЕТ ФАЙЛАМИ СБОРКИ, А НЕ САМИМ EXE-ЛАУНЧЕРОМ.
Для обновления EXE по-прежнему создаётся обычный GitHub Release лаунчера.

ГДЕ ХРАНИТСЯ СПИСОК СБОРКИ

Лаунчер читает файл:
https://raw.githubusercontent.com/jangofett158-ops/baranus-launcher/main/content-manifest.json

Этот файл находится в корне репозитория baranus-launcher и называется content-manifest.json.
Меняя его через GitHub, ты меняешь состав сборки без новой версии EXE.

ЧТО МОЖНО ДОБАВЛЯТЬ

- Моды, конфиги, шейдеры, ресурспаки и свои файлы.
- Только файлы, которые разрешено распространять их лицензией.
- НЕ загружай Minecraft.jar, библиотеки Mojang или готовую папку Minecraft: это нельзя распространять.

КАК ВЫГЛЯДИТ ОДИН ФАЙЛ В MANIFEST

{
  "name": "Название, которое увидит игрок",
  "path": "mods/имя-файла.jar",
  "url": "https://github.com/USER/REPO/releases/download/content-v1/имя-файла.jar",
  "sha256": "ХЕШ_SHA256"
}

path — путь внутри папки Forge-1.12.2. Разрешены только папки:
mods/, config/, shaderpacks/ и resourcepacks/.

url — прямая HTTPS-ссылка на файл.
sha256 — контрольная сумма файла. Она защищает от повреждённой или подменённой загрузки.

КАК ПОЛУЧИТЬ SHA-256 В WINDOWS

1. Открой PowerShell в папке, где лежит файл.
2. Выполни:

Get-FileHash .\имя-файла.jar -Algorithm SHA256

3. Скопируй значение из колонки Hash в поле sha256.

КАК ВЫПУСТИТЬ ОБНОВЛЕНИЕ СБОРКИ

1. Подготовь новые или изменённые файлы сборки.
2. Для собственных файлов или файлов с разрешённым распространением создай GitHub Release,
   например content-v1.1, и загрузи туда файлы.
3. Для каждого файла скопируй прямую ссылку Download и вставь её в url.
4. Открой content-manifest.json в репозитории и измени список assets.
5. Обязательно поменяй contentVersion, например:
   "contentVersion": "0.2.5-content.2"
6. Для каждого нового файла добавь sha256.
7. Сохрани изменения в ветку main.
8. Запусти лаунчер и нажми «Обновить». Он сравнит версию, скачает новые файлы
   и удалит только старые файлы, которые ранее сам отметил как файлы сборки.

КАК ДОБАВИТЬ МОД

1. Проверь, что лицензию мода можно распространять, или используй ссылку на официальный источник.
2. Добавь файл в GitHub Release либо используй официальный HTTPS-адрес.
3. Добавь объект в массив assets, например:

{
  "name": "Example Mod",
  "path": "mods/example-mod-1.12.2.jar",
  "url": "https://github.com/jangofett158-ops/baranus-launcher/releases/download/content-v1.1/example-mod-1.12.2.jar",
  "sha256": "ВСТАВЬ_СЮДА_SHA256"
}

4. Поменяй contentVersion и сохрани manifest.

КАК ОБНОВИТЬ ИЛИ ЗАМЕНИТЬ МОД

1. Загрузи новый JAR по новой ссылке.
2. В manifest измени url и sha256.
3. Если имя файла изменилось, измени path.
4. Поменяй contentVersion.
5. Старый файл будет удалён, если он ранее был добавлен лаунчером в managed-файлы.

КАК УДАЛИТЬ МОД ИЛИ ФАЙЛ

1. Удали объект этого файла из массива assets.
2. Поменяй contentVersion.
3. Сохрани manifest.
4. После нажатия «Обновить» лаунчер удалит только этот ранее управляемый файл.
   Файлы, добавленные игроком вручную, он не удаляет.

ВАЖНЫЙ ПОРЯДОК

Сначала загрузи файлы и убедись, что ссылки работают. Только потом меняй manifest.
Иначе игроки могут получить ссылку на ещё несуществующий файл.

ПРОВЕРКА ПЕРЕД ПУБЛИКАЦИЕЙ

1. Проверь JSON: запятые, кавычки и квадратные скобки.
2. Открой каждую url-ссылку в браузере.
3. Проверь SHA-256.
4. Измени contentVersion.
5. Протестируй обновление на отдельной тестовой папке Forge-1.12.2.

ЧТО ДЕЛАТЬ ПРИ ОШИБКЕ

- Открой «ЛОГ» в лаунчере.
- Проверь, существует ли ссылка url.
- Сверь sha256: он должен точно совпадать с файлом на сервере.
- Если GitHub manifest временно недоступен, лаунчер использует встроенный список текущей сборки,
  чтобы не оставить игрока без возможности запустить игру.
